# 🚀 Featured Project

## 🍜 Spicy Noodle RAG Chatbot System

### AI-powered restaurant recommendation and ordering assistant using RAG + LLM

A full-stack intelligent chatbot system for a spicy noodle restaurant that combines:

* Retrieval-Augmented Generation (RAG)
* Vector Database Search
* LLM-based recommendations
* Real-time conversational AI
* Admin-controlled AI prompt management
* Dynamic menu retrieval and recommendation pipeline

### Key Features

* AI chatbot for spicy noodle recommendations
* Personalized food suggestions based on user preferences
* Vector database retrieval for accurate menu context
* Admin dashboard for AI configuration
* Dynamic system prompt management
* Rebuild vector database directly from admin panel
* Full-stack architecture with Frontend, Backend, and RAG services
